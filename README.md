## Online-Learning-Management-System

## 📋 Project Overview
**Online Learning Management System (LMS)** is a software application or web-based technology used to plan, implement, and assess a specific learning process.

## 🚀 Features

- Add Faculty & Student details
- Update Faculty & Student details
- Delete Faculty & Student records
- View all Faculty & Student information
- Print Faculty & Student information
- Fees
- Exam form & Result
- Uttiles
- About

## 🛠️ Software Used

- **Programming Language:** Java
- **Database:** MySQL 
- **IDE:** IntelliJ IDEA 
## ✅ Requirements

Before running this project, ensure you have the following installed:

- [Java JDK 8 or later]
- [MySQL]
- [IDE - IntelliJ IDEA]
